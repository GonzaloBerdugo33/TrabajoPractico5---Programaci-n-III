# Trabajo Práctico 5 - Programación III

## API REST - Gestión de productos y stock

Proyecto desarrollado para el Trabajo Práctico 5 de Programación III.

### 🚀 API publicada /  📚 Swagger - Documentación y pruebas

La API se encuentra desplegada en Render:

[https://miapitp-api.onrender.com](https://miapitp-api.onrender.com)

## 🛠️ Tecnologías utilizadas

- .NET
- Entity Framework Core
- Base de datos relacional PostgreSQL
- JWT para autenticación y autorización
- Postman
- Render
- GitHub

## 📦 Funcionalidades

- Gestión de usuarios
- Autenticación y autorización mediante JWT
- Gestión de categorías de productos
- Gestión de productos
- Gestión de proveedores
- Gestión de clientes
- Registro de ingreso de productos
- Registro de salida de productos
- Control de stock
- Paginado de listados
- Carga de imágenes de productos
- Configuración de CORS

## 🗄️ Base de datos

La base de datos se encuentra publicada en Render y está conectada a la API.
